## YouTube Content Monetization Modeler

### Project Overview

The YouTube Content Monetization Modeler is a Machine Learning project developed to predict YouTube ad revenue using video performance metrics and engagement data.

The project uses multiple regression models to estimate the expected ad revenue (```ad_revenue_usd```) generated by a video based on factors such as:

- Views
- Likes
- Comments
- Watch Time
- Subscribers
- Video Category
- Device Type
- Country

A Streamlit web application is also developed to allow users to interactively test revenue predictions.

### Problem Statement

As content creators and media companies increasingly depend on YouTube monetization, predicting ad revenue becomes important for:

- Revenue forecasting
- Content strategy planning
- Audience engagement analysis
- Ad campaign optimization

The objective of this project is to build a regression-based machine learning model capable of predicting YouTube ad revenue accurately.

Dataset Information

- Dataset Name: YouTube Monetization Modeler
- Dataset Type: CSV
- Records: ~122,000 rows
- Target Variable: ad_revenue_usd

|Dataset|Features|
|-------|-----------|
|Feature|	Description|
|video_id|	Unique video identifier|
|date|	Upload/report date|
|views|	Total video views|
|likes|	Total likes|
|comments|	Total comments|
|watch_time_minutes|	Total watch time|
|video_length_minutes|	Video duration|
|subscribers|	Channel subscriber count|
|category|	Video category|
|device|	Viewer device type|
|country|	Viewer country|
|ad_revenue_usd|	Target revenue value|

## Project Workflow
## 1. Data Cleaning
Checked missing values
Filled numerical missing values using median
Removed duplicate rows
Performed outlier inspection using boxplots
## 2. Feature Engineering

Created additional meaningful features:

Engagement Rate
Watch Per View
Views Per Minute
## 3. Exploratory Data Analysis (EDA)

Performed:

Revenue distribution analysis
Revenue vs views analysis
Correlation heatmap
Revenue by category analysis
Revenue by device analysis
## 4. Model Building

Trained and evaluated multiple regression models:

Linear Regression
Ridge Regression
Lasso Regression
Random Forest Regressor
Gradient Boosting Regressor
## 5. Model Evaluation

Evaluation metrics used: 
- R² Score
- MAE (Mean Absolute Error)
- RMSE (Root Mean Squared Error)

Best model: Gradient Boosting Regressor
## 6. Streamlit Deployment

Built an interactive Streamlit application for:

- Revenue prediction
- Business insights visualization
- Feature importance analysis

## Key Insights
- Watch time is the strongest predictor of ad revenue.
- Higher engagement improves monetization.
- Better audience retention increases revenue potential.
- Different content categories generate different revenue levels.
- Viewer device and country also influence monetization patterns.
